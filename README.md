# Repositório de Projetos Integradores (TG)

Este repositório é destinado à hospedagem dos arquivos e códigos dos **Projetos Integradores (TG)** desenvolvidos ao longo do curso superior de Tecnologia em Ciência de Dados (2024–2027) na Fatec Votorantim.

> **Aviso de Privacidade:** Todos os dados sensíveis ou informações reais de clientes presentes nos projetos originais foram anonimizados ou removidos para garantir a conformidade com a privacidade, uma vez que este repositório possui visibilidade pública.
